## 能力边界

成员级调度，不保证账号/Key排序或会话每轮识别。树形预览是结构预览，不消耗随机/轮流状态，不承诺预测随机结果。8 层/64 调用是插件边界，不包括 CPA 内部重试。取消支持宿主回调返回取消错误时全树终止；插件没有新增宿主未提供的取消 API。模型字段只能校验上游声明，不能证明真实算力。生产服务未升级。
