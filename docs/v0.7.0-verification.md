## 完成审计后的取消补验（未发布修复）

独立审计拒绝原完成声明：fake host 直接返回 context.Canceled 绕过 JSON ABI，原发布包取消识别不充分。现已在工作区修复：提取实际 ABI 使用的 decodeHostResponse，host adapter 对零状态/499 的精确 context sentinel 消息恢复 errors.Is 身份并保留原 hostCallError。非精确文本和普通 502 不误判。host_test.go 覆盖真实 envelope 解码和取消/deadline 转换；race/vet/diff 均通过。

官方 CPA v8.0.16 隔离实验增加慢上游和客户端 0.3s 断开：非流和流各实际进入 cancel-leaf，3s 后无任何 cancel-sibling 调用；非流日志明确 request cancelled。流的断开由宿主生命周期结束，不将未观察到的插件取消日志宣传为已观察。已有资源关闭测试验证插件打开的 stream 在返回路径关闭。证据 /tmp/orangeguard-cancel-e2e-confirmed.log 与 test/e2e/.work/cpa.log。

此修复尚未包含在已发布的 d3d923b / v0.7.0 安装包中，不覆盖不可变发布资产；需用户决定发布补丁版本或明确授权替换版本契约后继续。原“全部完成”声明已撤回。

## 能力边界

成员级调度，不保证账号/Key排序或会话每轮识别。树形预览是结构预览，不消耗随机/轮流状态，不承诺预测随机结果。8 层/64 调用是插件边界，不包括 CPA 内部重试。取消支持宿主回调返回取消错误时全树终止；插件没有新增宿主未提供的取消 API。模型字段只能校验上游声明，不能证明真实算力。生产服务未升级。

发布前须再次执行最终测试和官方 CPA e2e；发布后核对 GitHub 最新正式版本、五个平台包、checksums 与 registry，流水线失败不得视为发布完成。
